## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or pnpm

### Development
```bash
# Install dependencies
npm install

# Start the dev server
npm run dev
```

Visit `http://localhost:5174/` (or the port specified in terminal).

### Production Build
```bash
npm run build
npm run preview
```

## 🛠️ Tech Stack
- **Framework**: React 19 + TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Typography**: Space Grotesk, Syne, Inter, JetBrains Mono
